Diagnóstico: Por que a escola perde 93% dos alunos?

Causa raiz: O NPS actual de 5.9 gera uma retenção mensal de apenas 87.2%. Isso significa que a escola perde 12.8% dos alunos por mês (~64 alunos), mas só adquire ~30 novos. O saldo líquido é de -34 alunos/mês. O loop de reforço negativo B1 (churn → menos receita → menos investimento → menos qualidade → mais churn) domina o sistema. A aquisição, mesmo com R$ 5.000/mês em marketing, não compensa a saída massiva.

Recomendações Estratégicas

1. RETENÇÃO É A SUPER-ALAVANCA (elasticidade 14.3x)
A retenção na faixa NPS=5 é o parâmetro mais sensível do sistema inteiro. Subir a retenção mensal de 87% para 96% elimina o loop de declínio e estabiliza a base. Isso exige elevar o NPS de 5.9 para 8.2 — uma transformação na experiência do aluno.
2. QUALIDADE DE ENSINO É O MOTOR (elasticidade 2.5x)
A qualidade base (hoje 7/10) alimenta directamente o NPS, que por sua vez controla retenção, referências e frequência. Subir para 8.1/10 (+16%) requer investir 2.5x mais em formação de professores (R$ 2k → R$ 5k/mês) — é o investimento com maior retorno sistémico.
3. MARKETING AMPLIFICA, NÃO RESOLVE (elasticidade 0.8x)
Aumentar marketing de R$ 5k para R$ 8.7k/mês (+74%) é necessário mas não suficiente sozinho. Marketing sem retenção é "encher um balde furado". A eficiência do marketing também precisa melhorar (de 0.002 para 0.0027 leads/R$) — conteúdo orgânico, SEO, parcerias locais.
4. CONVERSÃO E REFERÊNCIAS FECHAM O CICLO
A taxa de conversão de leads precisa subir de 15% para 19% (melhor processo de matrícula, aula experimental, follow-up). Referências orgânicas multiplicam-se com NPS alto — de 1.4% para 4.2% dos alunos trazendo novos leads. Estes dois efeitos criam o loop de reforço positivo R2.
5. CAPACIDADE DEVE ACOMPANHAR
Expandir de 800 para 947 vagas (+18%) previne que o loop balanceador B1 (pressão de capacidade → queda de qualidade) anule os ganhos de qualidade quando a escola crescer.
